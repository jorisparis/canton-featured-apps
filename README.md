# Canton Featured Apps

This repository hosts **Canton Featured App** documents.

A **CFA – 00XX** is a lightweight, descriptive record that documents:
- what a Canton Featured App does, and
- the activity markers it emits on Canton Network.

These documents are:
- **non-governance**
- **non-normative**
- **not Canton Improvement Proposals (CIPs)**

They exist to provide transparency & shared understanding of how Featured Apps interact with Canton Network.

Activity markers are defined in [CIP-0047](https://github.com/global-synchronizer-foundation/cips/blob/main/cip-0047/cip-0047.md).

## Scope

- This repository is **only** for apps that have already been designated as "Featured Apps" through [Canton Network processes](https://canton.foundation/featured-app-request/).
- Activity markers must be applied per [CIP-0047](https://github.com/global-synchronizer-foundation/cips/blob/main/cip-0047/cip-0047.md).
- Inclusion here does **not** grant Featured App status, nor validation for the use of activity markers.
- Each Featured App is represented by a single document with a stable identifier (**Canton Featured App – 00XX**), where `00XX` is the PR number that introduced the document. Identifiers are immutable once merged.

## Structure

- Each Featured App is documented in a standalone markdown file in the `cfas/` folder.
- Identifiers are immutable; content may evolve over time via pull requests.
