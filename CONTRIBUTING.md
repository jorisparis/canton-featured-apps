# Contributing to Canton Featured Apps

Thank you for contributing to the Canton Featured Apps repository.

This repository is maintained via public pull requests.

## What can be submitted

You may submit or update a **Canton Featured App – 00XX** document if:
- the app is in the process of getting featured or has already been designated as a *Featured App* by Canton Network Tokenomics Committee, and
- you are an authorized representative of the app, or submitting with the app team's consent.

## Naming convention

- Each document must be placed in the `cfas/` folder using the format:
  `cfas/CFA-00XX.md`
- The document title must use the full name:
  **Canton Featured App – 00XX**

The identifier (`00XX`) is the PR number that introduced the document. Identifiers are immutable once merged.

## Content expectations

Canton Featured App documents must:
- be factual and descriptive
- avoid marketing language or forward-looking promises
- clearly describe the app's interaction with Canton Network
- list declared activity markers and emission strategy

The submitting app team is responsible for the accuracy and upkeep of its document.

## Philosophy

This repository is a **good faith, community-driven transparency effort**. It does not have enforcement authority. The value comes from accurate, up-to-date documentation maintained by participating apps.

Reviews focus on following the template format, using correct naming conventions, and clarity of content. Reviews do **not** assess whether declared activity scenarios should be eligible for rewards—that determination occurs through separate Canton Network governance processes.

## Updates

- Updates are made via pull requests
- Significant updates should be noted in the document's changelog section
- Updates are expected when app marker behavior changes materially

## Deprecation

If an app no longer operates as a Featured App or ceases to emit app markers:
- The document should be deleted via pull request
- Git history preserves the historical record if needed
